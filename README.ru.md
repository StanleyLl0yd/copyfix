# CopyFix

[English](README.md) · **Русский**

**Чтобы текст после копирования оставался текстом, а не головоломкой.**

Копируешь абзац из PDF, вставляешь в письмо, а там каждая строка обрывается посреди предложения. Слова внезапно разрезаны переносами, пробелы живут собственной жизнью. Исправить вручную несложно, но когда это повторяется в десятый раз, хочется поручить кому-нибудь эту скучную работу.

Для этого и есть **CopyFix**. Небольшая утилита для Windows приводит в порядок текст в буфере обмена, не отвлекая от того, ради чего ты его вообще копировал.

Она работает **без интернета**, живёт в системном трее и предлагает проверить исправления, если результат нельзя определить однозначно.

**[Скачать CopyFix для Windows](https://github.com/StanleyLl0yd/copyfix/releases/latest)** · [Все выпуски](https://github.com/StanleyLl0yd/copyfix/releases)

## Меньше ручной правки, больше нормального текста

CopyFix особенно полезен для текста из PDF, документов и веб-страниц. В зависимости от режима он умеет:

- Приводить в порядок лишние пробелы, пустые строки и окончания строк.
- Предлагать склеить строки, которые оборвались посреди обычного абзаца.
- Находить слова, разорванные переносом, и предлагать соединить их, стараясь не потерять нужный дефис.
- Показывать исходный и исправленный текст рядом с подсветкой отличий.

Это **не** проверка орфографии и не ИИ-редактор. CopyFix не переписывает фразы и не пытается улучшить твой стиль. С кодом и структурированными данными он обращается осторожно, а сомнительные изменения **не применяет без подтверждения**.

## Как пользоваться

1. Скачай `CopyFix.exe` из последнего выпуска и запусти. Устанавливать программу и выдавать права администратора не нужно.
2. Скопируй текст как обычно.
3. Нажми **Ctrl+Alt+F9** (сочетание можно изменить) или выбери **«Исправить текст»** в меню трея.
4. Если появится предпросмотр, посмотри на подсвеченные изменения и подтверди их или отмени. После этого вставляй текст через **Ctrl+V**.

Передумал? Команда **«Отменить исправление»** в трее возвращает исходный обычный текст, пока в буфер обмена не скопировано что-то новое.

### Три режима на разные случаи

| Режим | Когда пригодится |
| --- | --- |
| **Бережный** | Убрать лишние пробелы и пустые строки, поправить окончания строк без серьёзного вмешательства. |
| **Умный** | Предложить соединить строки, разорванные внутри обычного абзаца. |
| **Глубокий** | Дополнительно разобраться со словами, разбитыми переносом. По умолчанию выбран при первом запуске. |

Режим выбирается в настройках. Интерфейс доступен **на русском и английском**: язык можно задать вручную или доверить выбор Windows. Для оформления есть **автоматическая, светлая и тёмная** темы.

## Маленькая программа без лишнего

CopyFix работает в **Windows 10 и 11 (x64)** и поставляется одним переносимым EXE. Ему не нужны аккаунт, облако, рекламные сервисы или дополнительные файлы рядом. Он не хранит историю буфера обмена, не собирает статистику использования и не следит за тем, что ты копируешь. Обработка запускается только по твоей команде; перехвата нажатий клавиш нет.

Внутри всё довольно приземлённо: **C++20 и нативный Win32**, интерфейс на системных GDI/DWM и RichEdit для сравнения текста. Без Electron, тяжёлых UI-фреймворков и отдельной среды .NET. Настройки хранятся в пользовательской ветке реестра Windows.

**О чём стоит помнить:** соединение строк и слов основано на эвристиках, поэтому предлагаемые изменения лучше просматривать. Если вместе с текстом в буфере есть форматирование (например, HTML или RTF), после применения останется обычный текст; отмена восстанавливает тоже только текст. CopyFix заранее покажет предупреждение в предпросмотре. Исполняемый файл пока **без цифровой подписи**; скачивать его стоит с официальной страницы Releases этого репозитория.

## Сборка из исходников

Нужны Visual Studio 2022 Build Tools (MSVC и Windows SDK) и CMake версии 3.21 или новее.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

Готовый файл: `build/Release/CopyFix.exe`. Среда выполнения MSVC включена в релизную сборку статически, отдельно устанавливать её не нужно. Подробности о внутреннем устройстве, тестах и ограничениях оставлены там, где им место: в [статусе проекта](docs/STATUS.md), [проверках Windows](docs/QA-WINDOWS.md) и [отчёте об аудите](docs/REPOSITORY-AUDIT-2026-11-03.md).

## Хочется помочь?

Даже у маленькой утилиты хватает неожиданных случаев. Если CopyFix неправильно обработал абзац, конфликтует с сочетанием клавиш или странно выглядит на твоём экране, [создай issue](https://github.com/StanleyLl0yd/copyfix/issues) и опиши, как это повторить. Идеи, проверка на разных версиях Windows, новые тестовые примеры и аккуратные pull request тоже очень кстати. Только убери из примеров личную и конфиденциальную информацию.

А если CopyFix избавил хотя бы от нескольких минут возни с текстом, можешь поставить репозиторию **⭐ звезду**. Так другим будет проще его найти.
